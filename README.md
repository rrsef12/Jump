# Jump 保存助手 · 0.1.0

Windows x64 原生便携应用。启动后驻留通知区域，标准“打开 / 另存为”窗口出现时自动显示助手；Blender 文件窗口可通过本机接入脚本自动关联。关闭文件窗口后自动收起，无需快捷键。

## 使用

1. 将发布包解压到一个固定文件夹，运行 `Jump.exe`。
2. 在软件中打开“另存为”。助手会显示在旁边；空间不足时使用底部布局，自动出现时不会抢走输入焦点。
3. 单击位置或名称即可填入，选中的项目会高亮。确认文件名后使用原窗口的“保存”，或在“整名编辑”的输入框中按 Enter。位置快捷项支持双击或 Ctrl + 单击提交；命名候选只负责修改字段。原软件的覆盖提示、格式设置和实际写入流程继续生效。
4. 点击方案名可直接切换方案；编号、撤销、重做和生效规则常驻命名区。更多字段和方案编辑从 **命名设置 ▾** 进入。位置管理从位置菜单进入。
5. 退出请使用通知区域菜单中的“退出 Jump”。关闭或最小化助手只会在本次文件窗口中隐藏，不关闭原软件。

顶部为软件名、与内容等宽的位置分段栏、自适应文件夹网格和单行路径，下方显示快速命名与带标签的最终文件名。编号旁常驻撤销、重做；还原本次名称与位置仍在“命名设置”菜单。侧边窗口宽 320 逻辑像素，高度随文件夹行数和工具展开自适应，空间不足时切换底部布局。快速命名按方案配置显示常用字段，其余字段及前后缀 / 替换规则按需展开；规则全部关闭时合并为“修饰规则”入口，启用后分别显示具体状态。长文件名增加完整换行展示，悬停也可查看全名。底部状态区在正常情况下紧凑显示能力入口，计算中使用同一行提示，输入错误和配置写入问题独立展开说明。

底部能力入口说明当前窗口的名称、目录、格式和编号能力；只能回填名称时会提示在原窗口选择目录，详情可进入接入诊断。

设置中心沿用主界面的深色配色、字体、圆角控件和下拉反馈，采用固定侧栏与内容区。窗口宽度为 792 逻辑像素，高度随内容调整并限制在当前屏幕内；较长的编辑表单支持滚动和键盘焦点跟随。命名方案、位置、流程、常规、前后缀、变量、项目、备份及接入工具均在同一窗口内切换。命名方案页使用新版字段编辑器，保存流程页编辑名称和目录。

设置中心标题会标明“未保存”。收藏、流程、常规选项、前后缀和变量模板在切换页面、选择其他条目或关闭时保护未保存的修改；选择“否”继续编辑，选择“是”放弃草稿。新增收藏仅在保存后加入配置，同一完整路径不重复收藏。保存失败时保留输入并恢复原配置，排除写入问题后可直接重试。常规选项保存成功在页面内提示；表单与方案编辑器支持 **Ctrl + S** 保存。

位置栏的放大镜打开位置搜索，也可在助手中按 **Ctrl + F**；**Ctrl + L** 直接编辑路径。命名方案列表显示选中方案的字段顺序和格式示例；示例不会扫描目录或写入原软件。自动编号仅统计实际文件，同名文件夹不会影响版本号。

**默认方案**：进入“方案设置 → 使用范围”，勾选“作为全局默认方案”，或通过“添加 exe…”关联软件，最后保存方案。设置中心的“软件关联与默认”直接定位到同一区域。新保存窗口优先使用软件关联方案，没有关联时使用全局默认；临时切换方案不改变默认。移除关联后跟随全局，取消自定义方案的全局默认后恢复“资产文件”。软件按 exe 文件名识别，不区分大小写。方案规则、默认设置和软件关联一起保存，取消全部撤回；复制方案不继承默认身份和软件关联。

主面板在支持的 Windows 11 上使用低透光的深色 Acrylic 毛玻璃、细描边与系统阴影。文字、图标和文件名输入区域保持清晰实色；位置分类使用等宽分段栏，以中性浅色底块标记当前分类，空状态说明与路径左对齐。方案入口采用紫色与图层图标；当前选中的位置和命名候选采用蓝色，候选同时显示勾选；已启用的自动编号与修饰规则使用中性深色底、灰白文字和低饱和青色图标。底部可用能力采用低强调的灰色文字与状态图标。关闭规则使用中性灰边框，不可用操作使用更暗的文字与图标；目录能力受限时使用琥珀色并显示原因。编号、前后缀、替换、撤销和重做各有对应图标。悬停有约 140ms 的短过渡，结束后停止绘制。关闭系统透明效果、高对比度、远程桌面或系统不支持时自动使用深色实底；关闭系统动画时直接切换状态。

保存位置快捷栏常驻主界面，提供推荐、收藏、最近、历史四个分类，按实际内容显示一到三行文件夹；一至两个文件夹均分一行，四个文件夹使用两行两列，其余按三列排列；只有一行时紧凑显示，超过三行后只在文件夹区域内滚动，支持滚轮和滚动条。有收藏位置时默认显示收藏；单击切换目录，当前目录高亮。分类切换不改变文件名；文件夹行数改变时整体重排，列表内部滚动时下方路径和命名区保持不动。路径旁的星标可收藏当前位置，调节菜单中的“管理收藏位置”可编辑收藏位置。打开文件窗口同样显示快捷栏。“收藏”只显示通过星标或收藏管理添加的文件夹，初始不自动收藏系统目录；取消收藏后立即移除，最近保存和浏览历史独立保留。“最近”只记录已确认文件保存成功的位置；“历史”记录在文件窗口浏览或跳转过的目录，即使未保存或取消保存也会留下记录。“推荐”合并资源管理器中已打开的文件夹，相同路径只显示一次，并在对应文件夹下标注“已打开”；所有已打开目录均可选择，不受普通推荐的六项数量限制。四个分类均有悬停说明。

保存位置区域底部以低强调的单行文字显示当前路径，悬停可查看完整路径；点击文字或铅笔图标，在原位输入完整文件夹路径，Enter 切换目录，Esc 或点击其他位置取消未确认的输入并退出编辑。路径旁的星标收藏或取消收藏当前目录。编辑路径期间暂停文件名自动同步；取消编辑后恢复名称同步。目录导航失败时保留输入以便修改。

可向文件名框或路径编辑框粘贴完整路径，例如 `D:\海港项目\交付\守卫_v012.png`。Jump 在后台核验后自动拆分目录与名称并填入，支持中文、空格、引号及正斜杠；已有文件夹路径只切换目录，保留名称。普通文字仍按输入框的原生粘贴处理。完整文件路径作为新的名称输入，清除本次组合规则和编号；原软件格式不匹配、目录不可访问或文件名无效时不应用，并提示原因。粘贴不提交保存；只对已确认具备目录操作能力的窗口开放。

右键路径文字选择“搜索位置…”可打开位置搜索面板。它合并收藏、最近保存、推荐、资源管理器文件夹与浏览历史，去重并保留当前路径，提供名称 / 路径搜索、星标收藏与常见系统文件夹。真实保存记录标注“最近”，仅浏览或取消不算保存。方向键浏览，Enter 选择，Space 切换收藏，Esc 关闭。

点击命名区的方案标题即可切换方案，也可从 **命名设置 → 方案设置…** 编辑。常用候选按字段显示，右键可改名；全部候选在对应字段的“更多”中查找。点击前后缀状态可临时输入，也可通过“＋”搜索和添加预设。

主要名称和下拉箭头共用一个边框。点击名称可手动输入，右侧箭头显示最近使用的 8 个名称，按最近使用排序并自动去重，重启后仍可复用；不同项目分别记录。输入后按 Enter、勾选收起或点击别处确认时记录，Esc 取消的输入不记录。选择历史主要名称只替换主要名称，保留文件类别、当前状态、前后缀及编号规则；输入时按 ↓ 也可打开下拉。已有保存记录中的主要名称也可作为历史选项。菜单统一使用深色背景、浅色文字、蓝灰选中态和勾选标记；高对比度模式沿用系统菜单。菜单宽度最多 440 逻辑像素并受屏幕宽度限制，较长名称以省略号展示，悬停或用方向键选中时显示完整名称提示。

主要名称下拉的 **移除最近名称** 子菜单可单独移除一项，不改变当前名称、其他项目或保存记录。移除结果在重启后保留，旧保存记录也不会重复补回；以后重新输入并确认该名称时会再次加入最近列表。长路径优先保留末尾目录，悬停仍可查看完整路径。

右键文件夹、前缀或后缀可设置颜色标记。文件夹颜色按完整路径保存，同一目录在不同分类中保持同色，取消收藏不清除颜色。

旧标签组合、分组及程序关联、独立当前状态／日期／编号管理页已删除。旧分组中的有效名称自动迁移为新版命名方案候选，超过 50 项自动拆分，同名方案自动避让；迁移不叠加编号。首次写入前保留原配置备份。原有字段方案、项目、收藏和保存记录继续可用。

## 这一版的功能

- **保存位置**：主界面显示推荐、收藏、最近、历史四类位置，自适应显示一到三行文件夹，超出后内部滚动，单击即可切换；路径栏的放大镜可打开搜索面板，输入名称或路径即可筛选，星标可直接收藏或取消收藏。位置合并后按路径去重，最近保存独立保留 20 条，重启后仍在。
- **最近保存**：支持 Jump 和原软件的保存按钮；标准保存窗口关闭后，确认对应文件被创建或更新才记录，浏览目录或取消保存不计入。记录在位置下拉中标为“最近”。只核验已知目标文件的元数据，不扫描目录或读取文件内容。
- **快速命名**：可自定义字段、顺序、候选、分隔符、固定文字、大小写、数字补零和出现条件；面板随方案生成。支持复制方案、逐项撤销和实时回填，规则默认值与本次资产名分开保存。
- **前后缀泡泡**：点击常驻的前后缀状态（或“命名设置 → 本次命名 → 前后缀”），原位展开前缀与后缀输入框和常用泡泡，可自由输入或直接点选组合使用。同类选项互相替换，再点已选项取消，选另一个名称仍保留已选前后缀。前后缀泡泡只填入，不会双击保存。点击“＋”弹出新增面板，泡泡右键菜单中的“管理预设”进入前后缀管理页，可新增、编辑、移除、上移或拖动排序，新增内容优先显示。支持 `{date}` 当天日期变量。
- **文件格式**：只写入文件名（不含扩展名）。最终文件名将名称和原软件的真实扩展名合并为一条只读预览（如 `守卫_v001.png`），长名称自动换行；修改格式请在原软件中操作。最终后缀和文件内容由原软件处理，不会固定成 `.txt`、`.png` 等格式。
- **可视化替换**：从“命名设置 → 本次命名 → 替换 / 正则”原位展开设置，不打开新窗口。内置文字替换、空格转下划线、删除数字、去括号内容、统一分隔符、去末尾版本号；支持简单自定义正则和 `$1` / `$2` 分组引用。匹配内容高亮，实时展示最终文件名；规则可独立启用或停用，收起后保留，清空后恢复未替换的名称；无效表达式或文件名不能应用。后缀文字添加在扩展名前，文件格式仍跟随原软件。
- **方案复用**：命名方案保存字段规则，跨保存窗口继续使用；原整套保存流程继续支持目录、名称、前后缀、当前状态、日期、编号、变量模板和替换规则。两者均可导入导出。
- **后台控制**：暂停自动显示、切换侧边 / 底部布局、清空历史、可选开机运行。

“历史”采用紧凑列表：主面板仅显示最近两条，每条整行显示文件夹名与上级路径，悬停可查看完整路径；更多记录通过“查看全部历史”打开，仅搜索浏览历史中的名称或路径。记录不会因收起而删除，其余位置分类仍使用文件夹快捷网格。

两处历史列表均可右键收藏或“从历史移除”。移除单条历史不删除文件夹，也不影响收藏和已核验的保存记录；当前窗口刷新不会立即加回，重新访问该目录或重新打开保存窗口时仍可产生新历史。

**最近** 页右上角的 **清空最近** 可清理全部最近保存位置；右键文件夹选择 **从最近移除** 可只删一条记录。**历史** 页同一位置提供 **清空历史**，清理全部浏览记录。两者分别清理各自记录，保留收藏、当前目录和文件名，不删除实际文件或文件夹。清理后立即更新并保存；历史不会被当前目录的定时刷新立即加回，下次访问其他目录或重新打开窗口时仍可产生新记录。下一次核验保存成功后会重新记录最近保存位置。

历史记录表示助手在文件窗口中识别到或跳转过的目录，不代表文件已写入。界面显示“已提交”仅表示原软件已收到保存操作，实际是否完成由原软件决定。

保存窗口关闭后若文件尚未写出，会临时等待目标目录的文件变更通知（最多 60 秒），只核验已知目标文件，不读取文件内容或枚举目录；通知不可用的文件系统保留短暂重试。带点的版本名称、原软件自动追加的格式后缀，以及用引号指定的无扩展名文件也纳入最近记录核验。

核验文件写入成功后，屏幕角落短暂显示实际文件名与位置，可点“打开所在目录”。提示不抢焦点，约 8 秒后收起；鼠标停留时延长显示，也可手动关闭。仅填入、提交但尚未写入、取消保存都不会直接产生成功提示。

## 快速命名

命名区显示可点击的方案标题、常用字段、编号、撤销 / 重做、生效规则和最终文件名。编号菜单可直接选择自动版本、序号或关闭，说明按当前目录、文件名（不含扩展名）和扩展名计算的范围；等待目录、计算中和待修正会显示相应状态。更多设置从右上角 **命名设置 ▾** 进入。默认资产方案保留主要名称、文件类别、当前状态直接点选，游戏方案按自己的字段顺序显示。

| 在命名设置中选择 | 用途 |
| --- | --- |
| 方案设置 | 统一编辑字段、常用选项、格式、目录推荐和软件关联 |
| 命名方案 | 切换已保存方案或示例；从名称建立、导入导出与删除 |
| 本次命名 | 全部字段、整名编辑、前后缀、替换 / 正则及清除修饰规则；直接选择自动版本、序号或关闭 |
| 撤销与还原 | 撤销、重做、恢复本次初始名称与位置；输入无效时仍可恢复 |
| 更多工具 | 交付、整套保存流程、项目及面板设置 |

**方案设置**：从 **命名设置 → 方案设置…** 或 **设置中心 → 命名方案 → 方案设置** 进入。页面按 **方案信息 → 生成预览 → 文件名结构 → 文件名格式 → 保存位置 → 保存操作** 排列，共用一份草稿和一次保存 / 取消。顶部直接显示保存后如何应用，点击 **更改范围…** 修改软件关联与全局默认；名称旁的 **···** 方案菜单提供 **复制为新方案**。

**文件名结构**：展示 `[文件类别]_[原文件名]_[自动版本]` 这样的组成结构和生成结果。中间按拼接顺序列出每一部分，**默认填入 / 自动内容** 列显示新保存窗口将使用的内容。来源标签区分原名带入、当前项目、当天日期、默认预填和固定只读。普通文字先用默认值，原名、项目和日期按来源自动获取；保存时手动输入或选择常用选项只替换本次内容，不修改方案。常用选项不会自行成为默认值；固定文字只读，已有选项保留供切换来源后使用。每行直接显示 **添加选项… / N 个选项…**、**编辑规则…** 和 **↑ / ↓ / ×**，至少保留一项。**＋ 添加命名部分** 支持主要名称、项目名称、日期、文件类别、补充说明、当前状态、手动编号、固定文字和自定义内容，最多 8 项；已有项定位编辑，不重复添加。

**主要名称** 使用原名来源时，中间列明确显示“使用保存窗口的原文件名”，不显示 `Asset` 作为方案默认。`Asset` 是管理界面初始化预览的样例，不是原名为空时的备用值；试填原名为空会提示填写。行内说明“手填或选项替换本次”，常用选项用于主动替换本次名称，不会自动覆盖原名。

每行的 **编辑规则…** 打开该部分的详情，有五个明确任务：**基础与来源、可选内容、填写与显示、文字处理、添加条件**。可选内容与条件已拆为独立页面。显示名称和 **写入文件名** 的文字可以不同，例如“静态模型”写入 `SM`；后者留空则使用显示名称。保存检查重复和无效文字；改名同步默认内容、条件与目录匹配，保留已有关键词、颜色。

**填写与显示** 分别设置是否参与命名、是否必填及是否在主面板直接显示。停用保留原规则；仅隐藏主面板输入仍可参与命名。**文字处理** 保留大小写、字符限制、数字补零、独立连接符及前后固定文字，**恢复原样** 一次关闭本页处理。**添加条件** 按另一部分写入文件名的文字匹配；不满足时不输出，也不校验必填，循环依赖会提示修正。

下方的 **文件名格式** 直接设置分隔符（可留空表示直接连接）和末尾自动版本 / 序号；旁边的 **编号设置…** 设置编号位数及版本字母大小写，下拉文字同步实际格式。**手动编号** 是独立的普通数字项，由用户填写，不自动续号。自动日期行的 **日期格式…** 直接定位日期来源设置，格式仍由本方案的全部自动日期部分共用。**保存位置** 显示目录推荐状态与规则数量，进入 **目录推荐…** 编辑目录规则及保存前同名检查。

**试填预览**：顶部直接输入测试原文件名，实时查看生成文件名；**模拟填写…** 填写文件类别等临时内容并查看输出解释，旁边的 **批量预览…** 支持逐行试原名、查看组成和错误。模拟输入与方案默认、主面板本次真实输入分别存储，切换任务保留试填，关闭编辑器后不持久化。解释区逐项说明输出来自哪里，或因未填写、停用、不符合条件、项目不可用而未输出。原名可带扩展名；扩展名保留到模拟结果，真实格式仍由原软件决定。自动编号始终标明是示例，真实保存时按目标目录重新计算。**按方案默认重新试填** 清除各部分的临时覆盖。

**新建与示例**：新建方案先进入示例选择，可预先看见“简单命名 · Rock”“游戏资源命名 · SM_Rock_v001”“从空白创建”等结构与结果。选择只是试用；点击 **采用这个示例，继续编辑** 后进入草稿，最后保存才写配置。采用示例建立新方案草稿，原方案保留。各示例保留独立草稿，可用 **返回原方案草稿** 恢复原来的修改；不再通过普通下拉框隐式提交方案。

**使用范围**：方案信息区显示“保存后自动应用”的软件或全局默认，以及“在主面板手动选择”的状态，旁边常驻 **更改范围…** 入口。页面说明 **软件专用方案优先，其次全局默认**，并说明如何从保存主面板手动选择。可勾选 **作为全局默认方案**，或 **添加 exe…** 关联软件。移除关联后跟随全局默认；临时切换方案不改默认。相关入口都定位到同一编辑器，修改一起保存或取消。

文件名结构使用统一表头的紧凑编辑表格：名称与来源、默认填入内容、选项与规则分别对齐，排序操作放在每行右下角。单项省去重复的组成概览，多项展示拼接顺序；复制、批量预览和目录推荐分别跟随方案、预览及保存位置。长条件缩成“条件：部分名称 = 输出文字”，超长名称和文字使用省略号；完整规则可悬停查看并在详情编辑。3～8 项时保持相同的控件尺寸，通过滚动和焦点跟随访问后面的部分。

**固定保存区**：保存、取消、修改状态和错误修正入口固定在窗口底部，正文在其上方滚动。新方案显示“新方案尚未保存”，已有方案在修改后显示“有未保存的修改”，撤回规则修改后恢复“尚无修改”；试填不会触发规则修改状态。键盘切换和错误定位将输入滚到固定底栏上方。


**目录推荐**：没有规则时显示“尚未配置”；有规则且开启时显示“已启用 · N 条规则”；关闭后显示“已关闭 · 保留 N 条规则”。点击状态文字或 **目录推荐…** 进入设置，最多 20 条，支持完整路径或相对项目根目录的路径，例如“某部分写入 SM → 推荐 Models”。关闭推荐保留规则；用户点击推荐才切换目录，不创建目录或提交保存。选项输出改名和内容删除会同步维护相关引用。

**同名提示**：在精确目标路径检查同名文件或文件夹，显示修改时间与大小；可换下一个编号、修改名称、打开文件夹或重新检查。它不读取工作文件内容、不空闲轮询；切换名称、目录或保存窗口会丢弃旧结果，失败明确提供重试。原软件继续负责最终覆盖确认。

**错误与草稿**：规则错误指出对应命名部分，**定位并修正…** 进入相关设置并保留填错的文字。模拟缺少必填内容只影响试效果，不会把临时输入变成默认值。详情中 **‹ 返回方案** 保留修改；取消不写规则。删除内容同时清理条件和目录引用；**复制为新方案** 保留规则和目录推荐，不继承全局默认身份与软件关联。保存方案仍保留主面板本次已填内容、临时前后缀、替换和未改变的临时编号语义。

设置中心支持调整窗口大小，长方案在较小视口中滚动，Tab 与错误定位会将输入滚入可见区域；DPI 变化重新布局并保留草稿。

默认资产字段统一叫 **项目名称、主要名称、文件类别、补充说明、当前状态、日期**。“补充说明”用于区分重甲、夜景、侧面等同一对象的不同内容，可留空。已有方案副本和保存记录中的旧默认字段名在读取时同步更新，用户自定义过的名称保留；查看和取消编辑不会写配置。

内置三个可修改的游戏行业示例，默认不追加自动版本：

| 示例 | 输出例子 | 规则 |
| --- | --- | --- |
| 游戏引擎资产 | `SM_Rock_A`、`T_Rock_A_N` | 文件类别、主要名称、补充说明；文件类别为 T 时显示贴图用途 |
| 贴图资源 | `T_Rock_A_BC` | 固定 T 前缀，主要名称、补充说明和 BC / N / ORM 用途 |
| 项目分类与编号 | `PRJ_Prop_Rock_001` | 项目前缀、分类、主要名称及三位编号 |

例如要输出 `PRJ_Prop_Rock-LOD01`，将字段顺序设为项目前缀、分类、主要名称、LOD；LOD 设置纯数字、补零 2 位、前固定文字 `LOD`、单独连接符 `-`。修改项目缩写、分类候选或字段顺序即可适配另一项目，无需改代码。

日常操作保留直接点选：

- 点击候选替换当前字段，再点已选的可选项可取消；必填项保留当前值。行末 **⋯** 提供其余候选、自定义和候选编辑。当前值不在常用项中时仍会显示。
- 最终文件名为只读文字预览，点击不会进入编辑或出现光标。修改请使用上方字段；**命名设置 → 本次命名 → 直接修改完整文件名** 会在上方显示独立输入框，底部仍只展示结果。下方状态说明使用无框的中性灰色文字，可点击查看接入详情。
- 右键最终文件名可选择 **复制完整文件名**，复制后标签短暂显示“已复制”。主要名称、全部字段、前后缀、整名编辑和替换表达式的输入错误显示在各自输入框附近，修正后自动收起；提示展开不会重建正在输入的控件。
- 点击字段值才展开输入框，输入即更新预览和原窗口。点击别处或 Enter 保留并收起，Esc 撤回本次输入；全部字段视图、前后缀和替换规则也支持点击别处收起。同组输入和候选之间切换、打开菜单时保持展开；中文组字中暂不收起，无效输入保留供修正。固定文字从 **命名设置** 中进入方案编辑修改。
- **右键候选即可改名**，同步更新显示和输出；选中项立即回填，未选中项不改变本次名称。已保存命名方案的候选、默认值及相关出现条件一起更新，重启仍生效。临时输入不改写候选库，保存历史也不会自动成为方案默认值。
- 在原保存窗口手动输入整名，快速命名继续显示，整名先原样保留；再次点选字段时恢复方案的其他默认值并组合。**还原** 恢复窗口初始名称与目录，保留当前方案；常驻的 **撤销 / 重做** 只回退命名，不改变保存位置。输入框内 Ctrl + Z 仍使用原生文字撤销。
- **本次命名 → 显示全部字段** 包含当前条件下的所有有效字段，展开后标题标明当前视图。前后缀与替换按需打开，收起后继续生效；菜单中勾选启用项，也可一键清除修饰规则。
- 末尾自动版本 / 序号独立于普通数字字段，可点击常驻的 **自动版本 / 编号** 入口（或 **命名设置 → 本次命名**）打开或关闭，当前方式有勾选标记。重新打开已核验保存的同一文件时，按软件、项目和实际路径恢复结构；开启自动版本时计算下一版。普通新窗口沿用自身文件名，不套用上一份资产名。
- 更改规则保存为方案默认配置，本次对象名与临时选择分开保存；取消编辑不改配置。最多 8 个单值字段、每字段 50 个候选，出现条件为每字段一条等值条件，支持依赖链。

完整保存流程统一从 **命名设置 → 更多工具 → 整套保存流程** 套用、保存或管理；项目设置也在“更多工具”。旧 JNS1 结构继续可读，新方案使用 JNS2 并在本地分段存储。打开文件窗口不会自动套用命名；文件格式和实际保存仍由原软件处理。

自动回填期间位置页签和原保存按钮保持稳定；提交等待当前回填完成，继续编辑会取消排队的保存请求。无效必填字段阻止 Jump 发起保存，原软件的直接保存仍由原软件决定。

实现与验证记录见 [快速命名交付说明](docs/quick-naming-delivery.md)。

## 项目、方案与可核验保存

托盘 **设置中心…** 统一管理命名方案、收藏位置、保存流程、常规选项、前后缀、变量表达式、项目、备份迁移和软件接入。左侧切换栏目，右侧直接查看或编辑；命名方案、字段常用选项、项目表单和迁移步骤都在这个窗口内完成。方案、选项和项目表单编辑中切换栏目或关闭窗口会提示放弃未保存的草稿，取消编辑不会写入配置。主面板的相关入口也定位到同一个设置中心。文件选择和操作确认仍使用原生对话框。

托盘一级菜单为“设置中心…”、“暂停自动显示”、“更多工具”和“退出 Jump”；暂停后显示“恢复自动显示”。更多工具保留备份、软件接入的栏目快捷入口和配置目录。保存记录、名称组成、组合撤销/重做仍从主界面操作。

- **后台编号**：版本和序号在独立后台任务中计算。编辑新名称、切换规则或目录会使旧任务失效；结果不覆盖更新的输入。预览期间可继续操作，点击 Jump 保存会重新扫描目标编号；变化时展示旧/新名称，默认不继续，确认后才提交。名称组成菜单中也可主动重新核验预览。两条计算线程有界运行，不占用窗口控制的后台队列；底层文件系统调用若长时间无响应，计算结果仍需等待，界面保持可用。
- **保存边界**：提交前编号核验适用于通过 Jump 发起的保存。直接点击原软件保存仍由原软件处理；检查与实际写入之间也可能有其他程序创建文件，因此保留原软件的覆盖确认。
- **轻量项目**：手动选择项目，分别保存根目录、项目变量、工作和交付相对位置。项目变量优先于方案默认值。项目位置进入推荐列表，也可从设置中心的“项目”栏目直接切换。切换项目会清空组合撤销历史；修改根目录后，相对目录方案使用新根目录。绝对路径方案保持其指定位置。工作目录必须已存在。
- **保存流程**：保存流程菜单中的“将当前整套设置保存为流程”会记住规则输入，编号和日期使用时计算，带 `{date}` 的已知前后缀预设保留动态日期。选择同名方案保存时可以明确替换。当前目录在项目根目录内时，方案自动保存相对位置；此类方案在未选择项目时明确提示。方案菜单可添加“角色交付”和“工作版本”示例，缺失变量在变量表达式编辑器中填写。本次方案变量修改先用于当前会话，需要复用时另存或替换方案。
- **组合撤销与重做**：菜单操作记录本次保存窗口中的字段、规则、方案等组合修改，最多 80 步。编号重新计算，不使用历史编号占位。直接编辑完整名称时保留可恢复的字段结构；原窗口改名会建立新的文字基准，清空过期组合规则，快速命名仍然保留。文字输入框继续使用原生文字撤销。“还原”仍恢复本次窗口初始名称和位置，也可撤销这次命名还原；组合撤销本身不回退目录。
- **名称组成**：按需显示命名字段、前后缀、替换规则、变量表达式、编号和最终名称。选择对应项目进入相关设置。规则跨片段处理时展示计算当前状态；错误保留具体原因。
- **保存记录**：最多保留 50 个通过文件元数据核验的实际路径、软件和本机核验时间，提供打开所在目录和复制完整路径。同一路径再次核验后移至最前。取消、只浏览和只提交不会直接写入成功记录；“已核验写入”不代表验证了文件内容。
- **迁移与恢复**：按编号选择命名方案、保存流程和项目导出；文件包含所选项目的变量和根目录，不含保存记录。导入时可以重新映射项目根目录，查看具体新增/重名结果；重名项自动加“导入”序号，保留原项。导入和恢复前先备份，备份失败则不更改配置。每次程序运行首次替换配置前自动保留一个副本，另外可手动备份，最多保留 5 份 `settings.ini.bak1` 至 `.bak5`，`.bak1` 最新。
- **本地接入诊断**：显示名称读写、目录读取/切换、格式读取、提交保存与目标文件核验的当前能力。诊断文本可查看和复制，省略路径、文件名、窗口标题、变量值及控件选择器。不会自动上传。

0.1.0 测试版便携包包含上述功能；首次使用与开机启动步骤见包内“开始使用.md”。

## 后台运行与配置

应用为原生 C++ / Win32 单进程。空闲时等待系统窗口事件，不扫描所有窗口。已关联的通用命名窗口处于前台时，每 700ms 核对一次文件名，关闭后停止；首次点选期间临时监听一次鼠标点击，结束或 20 秒后撤销。Ctrl+Alt+N 使用系统注册快捷键，不安装常驻键盘钩子。

没有网络请求、遥测、系统服务或驱动。通用控件接入通过 Windows UI Automation 读写输入框，无需向目标程序注入 DLL；Blender、Houdini 使用下述软件内接入，Houdini 包含匹配构建的桥接库。通过系统 Shell 接口读取资源管理器位置，不扫描磁盘或读取工作文件内容来推断目录。

启动时仅显示通知区域图标。**开机运行默认关闭**，需要时右键通知区域图标，进入“设置中心 → 常规”，勾选“开机后台运行”并点击“保存选项”；它仅创建当前用户启动文件夹中的 `Jump.lnk`，每次登录 Windows 后在后台启动，无需管理员权限。取消勾选并保存即可关闭。移动应用文件夹后，运行新位置的程序，保持勾选并重新保存此选项以更新快捷方式。

配置默认放在 `Jump.exe` 同目录的 `data/settings.ini`；如果该目录不可写，改用 `%LOCALAPPDATA%\Jump\settings.ini`。命名方案、关键词、输入框接入绑定和路径保存在本地，字符串采用 UTF-16 十六进制编码，属于可还原的数据，不是加密。保存采用临时文件加替换。

## 兼容范围

第一版验证了 Windows 的现代 `IFileSaveDialog / IFileOpenDialog` 和经典 `GetSaveFileName / GetOpenFileName` 文件窗口，中文 / 英文“保存”按钮。建议先在日常使用的软件里试一次。

**通用自定义保存窗口接入**：不按软件品牌或 UI 框架写死适配。对于标题为保存、另存为、Save / Save As、Export、导出等的非系统窗口，以及具有同进程禁用父窗口的模态窗口，通过 Windows UI Automation 识别唯一可写的文件名框，并用明确的保存按钮确认语义。文件名为空、保存按钮灰色也会识别并自动出现；只有调用保存时才要求按钮可用。点命名泡泡或「填入」直接回填到原窗口，不需要复制粘贴。

能力分别检查，互不冒充：

- **名称读写**：可见、启用、非密码且提供可写 ValuePattern 的唯一输入框。写入前核对原值、进程、窗口与目录，写入后读回；原窗口手动改名会更新命名基准。
- **目录读取**：支持文件名框中的绝对完整路径，或唯一的 Folder / Directory / Look in / 输出目录 / 保存位置等明确标注的路径控件。Qt 标准 QFileDialog 的 lookInCombo 对象路径也可识别。未知、相对路径或多个目录候选不猜选，自动编号不可用。具备可核验导航能力的 Qt 标准文件窗口及 WPS 一类面包屑文件窗口会显示与系统窗口相同的推荐、收藏、最近、历史及路径输入；其它控件只开放已确认的读取能力。
- **快速跳转**：系统窗口沿用原导航；Qt 标准 QFileDialog 共用框架导航，不依赖 SD 软件名。先核验目标是存在的目录，再让原窗口执行目录导航，以路径栏独立回读确认位置；保留空名称或原名称及格式，然后填入当前组合并按目标目录重算编号。导航不提交文件保存，不创建目录。目标不存在、实际是文件、控件变化或无法确认到达时报告失败。当前未提供任意自绘软件的路径栏手动绑定；不能把“可写文字框”直接当作导航接口。
- **自定义地址栏跳转**：具有“此电脑 / This PC”面包屑结构、唯一地址编辑入口和文件名控件的保存窗口，也显示完整快捷位置。兼容 Invoke 和旧版辅助功能默认动作，不按软件进程名硬编码。展开地址栏后，仅向核验过焦点的地址编辑框发送 Enter；跳转后重新展开地址栏读取实际目录，确认原名称保留。目录证据仅在本次窗口会话、同一面包屑控件和内容下有效；控件重建或内容变化后不沿用旧路径。虚拟位置可作为跳转起点，选择真实文件夹后才开放依赖目录的编号。
- **提交保存**：只有唯一、可见、启用且提供 InvokePattern 的 Save / Save As / Export / 保存 / 另存为 / 导出按钮才开放。面板右侧设置菜单 →「填入并调用原窗口保存」是明确的提交入口；普通泡泡、双击和「填入」不触发保存。调用前重新核验编号和控件，写入后再次核对目标；软件改变目录或控件时停止。调用的是原按钮，保留原软件的覆盖确认与导出选项；失败不会自动重试。
- **格式与记录**：名称中的扩展名不等于软件当前格式，Qt 标准文件窗口可读取当前格式筛选器，空文件名时可从单一明确扩展名（如 `*.png`）确定后缀；多个候选后缀不猜选。格式选择仍在原软件操作。目录和实际文件名已知时，只有观察到文件真实创建或更新才记入保存记录；窗口不关闭的导出器也会核验。仅填入、复制、点击按钮或取消不会冒充写入成功。

窗口没有及时出现时，在原保存窗口按 **Ctrl+Alt+J** 重新检测并唤出同一个 Jump 面板；它不依赖标题关键词，但仍核验文件名框和保存按钮，不向随机输入框写入。

若控件语义不明确，右键托盘 →「设置中心…」→「软件接入」→「指定输入框…」→ 点击原软件文件名框，或先选中它再按 **Ctrl+Alt+N**。唯一性和读写能力核验成功后才建立关联。记录按可执行文件、窗口类及精确标题限定，保存控件语义与结构，不保存坐标、窗口句柄或当时的文件名。可从“软件接入”栏目的关联列表中选择并解除关联；标题或控件结构变化时需要重新指定。

已移除脱离保存窗口的“独立命名并复制”入口。它无法读取真实目标目录、可靠计算编号或核验实际写入，容易让复制出来的名字与最终文件不一致。已关联保存窗口后，仍可从面板设置菜单复制当前完整文件名；这只作为人工接管当前窗口的后备操作，不替代自动填入、提交和写入核验。

这是分层兼容方案，不保证任意软件都能自动操作。本机已在 Substance 3D Designer 15.0.0 的真实 Save Image 窗口验证空名称时自动出现、目录与 PNG 格式读取、标签直接回填，并恢复空名称；未提交图像保存。也已用 SD 自带 Qt 运行库的独立 QFileDialog 验证任意标题的模态保存窗口、自动编号、快速目录跳转及打开窗口排除。本轮快速跳转测试使用同一 Qt 运行库的独立窗口，尚未在 SD 的真实 Save Image 上单独重跑目录切换。本机 WPS Office 12.1.0.28505 的真实“新建文档→另存为”已验证最近位置跳转、从“此电脑”进入真实目录、手动路径跳转和原名称、Word 格式保留，没有提交文档保存。其他 WPS、Qt、Electron 应用版本仍需实际验证，管理员权限进程、云端虚拟目录、未提供 UIA 的控件可能只能复制；具有脚本接口的软件仍可用专用接入获得目录切换和更可靠的格式读取。「当前接入与诊断」会分别说明已确认的能力。

**Blender**：安装一次接入脚本后，打开 Blender 的保存 / 导出文件窗口，Jump 自动在旁边出现。名称泡泡、多字段组合、前后缀、当前状态 / 日期、替换 / 正则沿用现有界面和预设，直接同步原文件窗口，不需要全选、复制粘贴或快捷键唤出。目录可从 Jump 切换，扩展名跟随 Blender 当前格式。保存或导出仍执行 Blender 原操作，保留导出选项与覆盖确认；窗口关闭后自动收起，仅在文件真实创建或更新后记录最近保存位置。

在 Blender 5.2.2 LTS 上实际验证了 `.blend` 保存、FBX 导出、GLB 导出、中文组合命名、目录切换、自动出现与收起。当前适配使用 Blender 自带文件浏览器的独立窗口（中文 / 英文标题），不接管资产浏览器、节点参数或另写自定义 UI 的第三方导出器。其他使用相同文件浏览器的内置导出器共用适配，但尚未逐一实测。

开发版安装方式：运行 `integrations/blender/install.ps1 -Version 5.2`，将脚本和只允许当前 Jump 可执行文件接入的配置写入当前用户的 Blender `scripts/startup`。之后 Blender 启动自动加载；无需改场景、保存工程或启用外部脚本自动执行设置。已经运行的 Blender 会话可在 Python Console 执行 `import jump_save_bridge; jump_save_bridge.register()` 后恢复原编辑器；若模块尚不在搜索路径，需先将该版本的 `scripts/startup` 加入 `sys.path`。开发启动器只更新已经为本工作区安装的脚本，不自动接入其他版本。脚本更新后，已有会话需重新加载模块或下次启动 Blender 生效。

接入通过校验两端进程身份的本机命名管道读写 Blender 文件浏览器参数，不使用网络、键盘注入或坐标点击。只在文件浏览器打开期间以短定时器处理请求；关闭后停止计时。Jump 没有运行时，脚本不会启动 Jump，也不会自行保存文件。

**Houdini 工程保存（保留原生窗口）**：首次 Ctrl+S、菜单 Save As、Ctrl+Shift+S 打开 Houdini 自己的文件窗口时，Jump 自动出现。名称标签、多字段组合及命名规则直接回填原文件名栏；再次点击可撤销标签。切换目录保留已组合的名称，最终由原窗口 Accept 或 Jump 的 Enter 调用原 Accept 完成保存。取消、覆盖确认和实际工程保存继续由 Houdini 处理；已保存工程的 Ctrl+S 保持直接保存。接入不会创建系统保存窗口，也不调用 `hou.hipFile.save`。独立导出和节点内导出暂不接入。

当前适配限定 **Houdini 22.0.368 / Python 3.13 / Windows x64**。先运行 `integrations/houdini/build_native.ps1` 编译匹配本机 HDK 的桥接库，再运行 `integrations/houdini/install.ps1` 安装，下次启动 Houdini 生效。桥接库通过该构建导出的原生 UI 函数访问原文件窗口，部分函数不属于稳定的公开接口，因此严格核验完整版本；其他构建不启用，不做内存偏移猜测。`.hip` / `.hiplc` / `.hipnc` 等原格式保持不变；非商业许可证和其他界面语言尚未实机验证。

脚本和桥接库放在用户 Houdini 目录的独立 `jump_scene_save` 包中，通过 `pythonX.Ylibs/uiready.py` 加载，不覆盖已有启动脚本，不修改 `houdini.env`、节点或工程内容。本机命名管道校验请求方 Jump 的可执行文件，UI 线程处理名称读写；不使用网络、键盘注入或坐标点击。空闲时每 250ms 轻量检查 Qt 窗口，原保存窗口打开期间才读取原生字段和处理请求，以覆盖 Houdini 复用窗口的情况。Jump 未运行时仍使用原窗口；脚本不会自行启动 Jump 或保存。Python 工具通过 `hou.ui.selectFile` 打开的窗口会跳过。`integrations/houdini/uninstall.ps1` 可停用接入；开发启动器只同步已安装的新版脚本，桥接库更新需要重新运行安装脚本。

22.0.368 上已用独立实例实测首次保存、重复另存为自动唤起、中文多字段回填及撤销、切换目录保留名称、原 Accept 与 Jump Enter 真实 `.hip` 保存、取消和工具选择窗口排除。

“当前关联”仅在文件名控件或宿主窗口标题提供可验证的本地绝对文件路径时显示。许多软件只提供文档标题，因此无法普遍获取原文件位置；这种情况下仍可使用常用、历史和资源管理器的位置。

本机测试是在 Windows 11 x64 下完成，Windows 10 x64 未单独实测。该版本未进行代码签名。

## 构建与验证

日常改界面可直接双击根目录的 **`Start-Test.cmd`**：自动关闭上次测试进程，源码有变化时编译开发版，然后显示真实保存窗口。源码没变则直接复用已有程序，整个过程不打包、不更新 `dist`。它会退出本项目的便携版，避免两个助手重复出现。

测试预设独立保存在 `build/dev/settings.ini`，重复启动会保留；测试文件默认保存到 `build/dev/saves`。平时只需修改源码并再次双击此入口。

```powershell
.\Start-Test.cmd                   # 一键更新并测试现代保存窗口
.\Start-Test.cmd -Mode Classic     # 经典保存窗口
.\Start-Test.cmd -Mode Open        # 打开窗口
.\Start-Test.cmd -Mode Manage      # 直接测试预设管理
.\Start-Test.cmd -Mode Background  # 后台测试，可打开自己软件的另存为
.\Start-Test.cmd -NoBuild          # 直接启动上次构建的程序
.\Start-Test.cmd -Stop             # 退出开发测试进程
```

需要 Visual Studio 2022 C++ Build Tools 和 Windows SDK。日常开发使用 `dev.ps1`，只构建 Debug；便携发布单独运行 `package.ps1`。

原生端到端测试只操作自建保存窗口，在 `tests/output` 中写入隔离测试文件。新版字段编辑、候选改名、自动同步、完整保存流程、方案迁移、管理入口和显示材质均有相应检查；`native_integration.py` 仅提供通用测试辅助函数。旧标签模式专属场景已随功能删除。

系统文件夹回归会在当前用户的真实下载目录创建带随机名称的测试文件，核验原窗口和 Jump 的保存、最近记录与重启恢复后，仅删除内容匹配的测试文件；桌面和文档只验证路径识别。系统文件夹路径通过 Windows 接口解析，支持本地化显示名称和重定向路径。

管理窗口启动回归专门覆盖开发启动器和启动快捷方式使用的 `STARTF_USESHOWWINDOW / SW_HIDE`，核验首次显示、复用和最小化恢复；只使用隔离配置和 Jump 自己的窗口。`--manage` 可直接打开管理窗口，`--config 路径` 可使用独立配置。发布包不包含测试宿主。

## 分开运行回归检查

先使用 `dev.ps1` 更新开发版。隐藏检查与真实前台交互检查分开运行：

```powershell
python -X utf8 tests/run_checks.py
.\dev.ps1 -Stop
python -X utf8 tests/run_checks.py --foreground
# 也可只运行相关前台检查：
python -X utf8 tests/run_checks.py --foreground --only workflow_integration.py recent_saves_integration.py
```

前台检查仅使用 Jump 和自建测试宿主，顺序执行。`generic_integration.py` 使用自建的非系统保存窗口，覆盖目录识别、手动关联、编号冲突、原覆盖确认、歧义/只读/密码拒绝、填入时目录变化、保持打开的导出器核验及独立复制。通用测试辅助模块使用工作区独立的互斥锁，拒绝并行运行前台测试。运行期间需要测试窗口处于前台；不要同时运行其他交互套件。报告与日志保存在 `tests/output/check-runs`。Qt 专项测试为可选的 `tests/qt_save_integration.py --python <含 PySide6 的 python.exe> --qt-root <Qt DLL 所在目录>`；只创建自有窗口和隔离配置，不安装插件。编号的慢目录、过期结果和取消使用可控任务模拟验证；实际网络共享的响应时间取决于文件系统。

## 实测资源占用

本机在使用文件窗口与预设管理后，5 秒空闲采样的 CPU 时间增量为 0、文件 I/O 次数增量为 0，工作集约 28 MB，私有内存约 4 MB。具体数值见测试报告；这是短时本机测量，实际占用会随系统、UI Automation 提供程序及操作变化，无法承诺对性能完全没有影响。

自定义面包屑导航回归：`tests/breadcrumb_integration.py --python <含 PySide6 的 python.exe> --qt-root <Qt DLL 所在目录>`。独立自建控件覆盖虚拟起点、独立回读、中文空格路径、无效目录/文件路径拒绝、地址回显但未导航时不报成功、多个地址栏拒绝。Qt / 面包屑测试使用 `--test-target-pid` 绑定自建进程；相关原生回归使用 `--test-host-only` 限定当前构建目录中的测试宿主，避免测试实例接入用户仍开着的保存窗口。
