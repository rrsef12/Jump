# 2026-10-19 使用体验与可靠性改进

本轮完成了一次面向日常操作的检查与修正，开发版已通过 `dev.ps1` 更新。双击项目根目录的 `Start-Test.cmd` 可打开新版与真实 Windows 保存测试窗口；配置继续使用 `build/dev/settings.ini`。

## 已完成

- **设置草稿保护**：收藏、流程、常规、前后缀和变量模板显示“未保存”。切换页面、选择其他记录、切换前后缀分类和关闭窗口时可选择继续编辑。切换变量编辑模式或点选变量字段不会误清除草稿状态；将内容改回原值会自动解除未保存标记。
- **收藏先编辑再保存**：新增收藏不再立即进入配置，避免移动设置窗口等其他写入操作顺带保存未完成的记录。完整路径规范化后检查重复，支持引号和正斜杠；限制最多 100 项。首项的上移、空列表的移除等无效操作会禁用。
- **保存失败可以重试**：收藏、流程、前后缀、排序和常规选项写入失败时恢复原配置。保存表单保留输入，解除文件占用后可直接重试。前后缀右键移除和示例流程添加也补齐失败回退。配置写入会检查落盘刷新结果。
- **减少确认打断**：常规选项保存成功直接在页面中提示；失败同样在页面中说明。设置表单和方案编辑器支持 Ctrl+S 保存，保存按钮提供快捷键提示。
- **位置搜索可见**：路径旁增加放大镜按钮，Ctrl+F 搜索收藏、最近、历史及已打开目录；Ctrl+L 直接编辑路径。现有的星标收藏和铅笔编辑继续保留。
- **方案选择更清楚**：设置中心显示选中方案的字段顺序和格式示例，空列表给出新建入口说明。示例不扫描保存目录，也不写入原软件。
- **命名边界修正**：补齐 Windows 保留设备名检查，包括上标数字 COM/LPT、CONIN$/CONOUT$ 等。自动版本和序号只统计文件，忽略同名文件夹。
