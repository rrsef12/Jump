# 2026-10-19 主面板体验改进

本轮按体验评估落实常用入口、规则可见性和能力说明。按用户后续要求，按软件自动选择 SM / T 等命名预设留待单独处理。

## 已完成

- 点击方案标题即可直接选择命名方案，保留原有“命名设置”的完整功能。
- 文件名上方常驻自动版本 / 序号入口、撤销及重做；编号菜单说明查找范围和目录要求，入口显示当前编号及计算状态。
- 前后缀与替换规则常驻显示当前状态，点击可原位编辑；收起后仍显示正在生效的设置。
- 主体右侧增加最近名称下拉，保留最近 8 项，去重并按项目持久化；确认输入和选用历史时更新，Esc 取消和无效输入不记录。选择历史只替换主体，保留其他命名规则，支持撤销与重做。
- 所有 Jump 弹出菜单统一深色背景、文字及勾选样式，保留原生键盘导航和子菜单；主体文字和历史箭头共用一个输入框，输入时可用箭头与勾选。
- 最终文件名增加标签，收紧正常状态下的底部留白；计算提示复用能力行，错误说明单独展开。前后缀与替换均关闭时合并入口，生效时分别显示状态。长菜单限制宽度，并为截断项提供完整名称提示。
- 最终文件名改为无输入框边框的只读文字，整名编辑移至上方独立输入区；底部能力说明取消图标、箭头与框线，使用低强调的中性灰色文字，保留点击查看详情。
- 名称与原软件的真实扩展名合并为完整的只读预览，长名称在同一区域自动换行，取消独立格式栏与重复的完整名称行。
- 结果区右键可复制完整文件名，标签短暂显示“已复制”；主体下拉增加单条移除入口，按项目持久化移除结果并过滤旧保存记录回补，重新输入确认后可重新加入。路径显示优先保留末尾目录，悬停查看全路径。
- 输入错误显示在主体、全部字段、前后缀、整名或替换表达式附近，修正后自动收起，不重建输入控件；配置写入问题仍保留底部说明。该轮仅运行 `experience_details_integration.py`，覆盖复制、重启后的移除、路径展示与局部错误恢复。
- 根据后续反馈，移除主面板及菜单中的使用引导入口，命名区直接显示方案与常用操作。
- 底部说明当前窗口的名称、目录、格式和编号能力，可进入接入详情。名称回填与目录跳转分别说明。
- 设置中心区分常用页面与高级工具，解释命名方案和保存流程的用途；没有保存窗口时，说明“使用方案”不可用的原因。
- 长文件名完整换行展示，连续英文与下划线也能换行；输入期间保留原编辑控件和光标。中文组字期间不允许通过新增的撤销入口中断输入。

## 配色与图标修订

主面板补齐功能与状态的视觉区分：方案入口使用紫色与图层图标，选中候选使用蓝底和勾选。根据使用反馈，已启用的编号与修饰规则取消绿色底和绿色文字，使用中性深色底、灰白文字与低饱和青色图标；底部可用能力进一步降低强调。目录能力受限使用琥珀色及说明。普通按钮、关闭规则和不可用操作通过背景、描边及文字明暗区分。编号、前后缀、替换、撤销、重做及能力说明分别使用对应的矢量图标；文字、悬停提示和键盘焦点继续保留。撤销 / 重做按钮略微加宽，容纳图标和文字。

这次修订的相关检查为 `layout_smoke.py`、`quick_picks_integration.py`、`fill_paint_integration.py` 和 `material_integration.py`；同时复核 100/125/150% 缩放、侧边 / 底部布局和规则生效状态的截图。

改动前的源码、README 和开发配置位于 `build/experience-app-presets-backup-20261019-161514/`。该文件夹名称来自最初计划，其中的软件预设功能随后已按用户要求移出本轮范围。
